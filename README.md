# Опора

Персональный адаптивный дневник на три тренировки в неделю. Статический сайт без зависимостей и аккаунтов. Полная программа A/B/C восстановлена из исходного чата. Для диапазонов 2–3 подхода выбран нижний объём, что отмечено в карточках.

## Локальный запуск

Требуется Node.js 18 или новее. В папке проекта выполните:

```sh
npm run dev
```

Откройте http://localhost:4173. Для проверки JavaScript: `npm run build`. Устанавливать зависимости не нужно.

## Vercel

Загрузите эту папку в Git-репозиторий и импортируйте его в Vercel. Framework: Other. Build command: `npm run build`. Output directory: `dist`. Настройки также записаны в `vercel.json`. Либо выполните `npx vercel` из папки проекта, затем `npx vercel --prod` для публикации. Публикация в аккаунт Vercel в рамках этой задачи не выполнялась.

## Использование

- Переключатель A/B/C хранит три независимые текущие тренировки.
- Для каждого подхода доступны вес, повторы и отметка выполнения. Для односторонних движений повторы или секунды вводятся отдельно для левой и правой стороны; отметка означает выполнение обеих сторон. Вес гантелей записывайте за одну гантель, тренажёра или блока согласно его шкале; придерживайтесь одной системы.
- Отдых выбирается вручную: 60, 90 или 120 секунд. Таймер не стартует автоматически от отметки подхода. При скрытой вкладке время рассчитывается по часам устройства. Сигнал в фоне и при заблокированном экране не гарантируется.
- «Начать следующую тренировку» после подтверждения очищает отметки и заметки выбранного дня, сохраняя веса и повторы. История прошлых тренировок не хранится.
- Данные сохраняются в localStorage данного браузера и адреса. Очистка данных сайта удаляет записи; локальная и опубликованная версии не делят данные. При недоступном хранилище показано предупреждение. Синхронизации и облачного хранения нет.
- Шрифт Manrope загружается из Google Fonts. Без сети используется системный шрифт. Для самого сайта нужен доступ к серверу; полноценный офлайн-режим не заявлен.

## Ограничения программы

Это не медицинская рекомендация и не программа коррекции сколиоза. В исходном чате упомянут CIDP. Программу и технику следует согласовать с врачом или реабилитологом. Порог боли 0–2/10 из чата не является гарантией безопасности. При усилении симптомов остановиться и обратиться к специалисту.

Источник общих рекомендаций: https://www.nhs.uk/conditions/scoliosis/treatment-in-adults/ .
